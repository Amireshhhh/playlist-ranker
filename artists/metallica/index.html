How to read the proof

Every test treats a song as the unit, so a chorus repeated many times counts as one piece of evidence. p is the chance of a result this extreme if the pattern were noise. q is p corrected (Benjamini-Hochberg) for the other tests in the same family. Held means q < 0.05; Partly means p < 0.05 that does not survive the correction. Contractions are expanded, so “I'm” counts as “I am”. With n albums the smallest possible exact p for an album trend is 2/n!.
