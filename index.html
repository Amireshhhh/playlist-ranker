Analyse your own playlist

Export a Spotify playlist with Exportify (CSV), or use any public Deezer playlist, then run:

pip install -r requirements-insights.txt
python -m insights analyze my_playlist.csv --user me

An artist study: python -m insights artist "Gojira". Everything runs on your machine.

Our promise

We never store or publish lyrics. Lyrics are read in memory while a page is built and thrown away. Pages hold counts, scores and statistics only; the build fails if lyrics text is found on disk. Every claim on an artist page comes with its test, p-value and method, including the ones that failed.

Data: MusicBrainz (studio albums), LRCLIB (lyrics, read only), Deezer, Wikipedia. Built 2026-11-05 17:52 UTC from commit e00ce41. Source: playlist-ranker.
